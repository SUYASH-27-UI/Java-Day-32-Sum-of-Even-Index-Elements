# Java Day 32 - Sum of Elements at Even Indexes

This Java program calculates the sum of array elements stored at even index positions.

## Example

Array:
```text
[10, 20, 30, 40, 50, 60]
```

Even indexes: `0, 2, 4`

Output:
```text
Sum of elements at even indexes = 90
```

## Concepts Used

- Arrays
- `for` loop
- `if` statement
- Modulus operator `%`
- Array indexing
- Sum calculation

## How It Works

The program loops through the array and checks whether each index is even. If the index is even, its element is added to the sum. Finally, the total is displayed.
